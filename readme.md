# Player

A Personnal Music Streaming Service with a Web interface.

Plays music on the host server, on  client device (android) or a Upnp/DLNA compatible DMR.

Features :

- Aspie level Browsing capabilities with unlimited tag management and creation.
- Displays album cover, artworks and album infos.
- Customizable Web UI.
- Embded Gstreamer/playbin audio player.
- Custom REST API with over 50 routes.
- Embded UPNP File Server.
- Embded UPNP Controler to control a Hardware DMR (streamer).
- Audio Transcoding engine.
- Control app for Linux/Windows/Mac/Android ( see the other repo)


Witten with Python/Flask/Gstreamer/MongodB.
Docker image available.
